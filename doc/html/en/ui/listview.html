ListView Class

UI Class

Vertical listbox control for displaying and selecting items.

Description

The UI::ListView class (located in framework/controls/ListView.pbi) wraps PureBasic's ListViewGadget. It provides a simple scrollable list of text items with selection tracking and event dispatching.
