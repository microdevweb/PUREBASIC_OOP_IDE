Container Class

WPF Layout

Abstract base class for responsive WPF-style layout panels.

Description

The abstract UI::Layouts::Container class (inheriting from UI::Component) is the foundation of all responsive layout panels. It manages child component collections, internal padding, and recursive arrangement calculations.
