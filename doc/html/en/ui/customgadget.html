Abstract base class for custom 2D Vector / Canvas-rendered controls.

Description

The abstract UI::CustomGadget class (in src/ui/CustomGadget.pbo) extends UI::Gadget to build advanced custom widgets rendered on native PureBasic CanvasGadget with built-in state management (Hover, Pressed, Focus, Mouse coordinates).
