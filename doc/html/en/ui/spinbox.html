SpinBox Class

UI Class

Numerical input box with integrated up/down increment buttons.

🖇 Inheritance Hierarchy

Description

The UI::SpinBox class (located in framework/controls/SpinBox.pbi) wraps PureBasic's SpinGadget. It combines a direct numerical text entry field with stepper buttons.
