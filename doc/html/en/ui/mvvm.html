MVVM Architecture & DataBinding

MVVM Core

Complete Model-View-ViewModel architecture with observable properties and two-way binding.

🖇 Inheritance Hierarchy
Core::Object → MVVM::ObservableObject → MVVM::ViewModelBase

MVVM Architecture Overview

PureBasic OOP incorporates a comprehensive MVVM (Model-View-ViewModel) subsystem inspired by modern WPF and .NET MAUI standards. It decouples core business logic from graphical user interfaces using reactive DataBinding.

  • Model : Application state, domain rules, and data structures.
  • ViewModel : Exposes typed observable properties (MVVM::StringProperty, MVVM::IntProperty...) inheriting from MVVM::ViewModelBase.
  • View : Declarative layout definition (via XML or OOP code) with {Binding PropertyName, Mode=TwoWay} markup expressions.
  • BindingEngine : Automatically synchronizes UI controls and ViewModel properties bidirectionally.

Directory Organization & Zero-Include Framework

Standardized, decoupled project tree structure for your MVVM applications:

Recommended LayoutProject Tree
MyMVVMProject/
├── constants/
│   └── AppConstants.pbi         ; Shared Property & Command Identifiers
├── models/
│   └── TaskModel.pbi            ; Data entities & pure domain logic (optional)
├── viewmodels/
│   └── TaskViewModel.pbo        ; ViewModel class inheriting MVVM::ViewModelBase
├── views/
│   └── MainView.xml             ; Declarative XML View
└── main.pb                      ; Main executable entry point

Zero-Include Framework: With the PBO Transpiler, the framework (framework/UI.pbi) is automatically detected and injected into memory whenever UI:: or MVVM:: namespaces are used. You no longer need to write manual framework includes!

Standard Include Order in your main.pb:

EnableExplicit
; 1. Shared Constants
XIncludeFile "constants/AppConstants.pbi"
; 2. Data Models (if any)
; XIncludeFile "models/TaskModel.pbi"
; 3. Transpiled ViewModels
XIncludeFile "viewmodels/TaskViewModel.pbo"

Complete 4-File Quick Start Tutorial

1. Shared Constants (constants/AppConstants.pbi)PBI
#PROP_CLICK_MESSAGE = "ClickMessage"
#PROP_CLICK_COUNT   = "ClickCount"
#CMD_INCREMENT      = "IncrementCommand"
2. The ViewModel (viewmodels/MainViewModel.pbo)PBO
XIncludeFile "../constants/AppConstants.pbi"

Class MainViewModel Extends MVVM::ViewModelBase {
  Public *ClickMessage.MVVM::StringProperty
  Public *ClickCount.MVVM::IntProperty
  
  Public Method Init() {
    Super\Init()
    This\*ClickMessage = This\BindString(#PROP_CLICK_MESSAGE, "Welcome!")
    This\*ClickCount   = This\BindInt(#PROP_CLICK_COUNT, 0)
  }
  
  Public Method OnCommand(cmdName.s) {
    If cmdName = #CMD_INCREMENT
      Protected count.i = This\*ClickCount\GetValue() + 1
      This\*ClickCount\SetValue(count)
      This\*ClickMessage\SetValue("Click #" + Str(count) + " recorded!")
    EndIf
  }
}
3. The Declarative View (views/MainView.xml)XML
<Window Title="MVVM Demo" Width="420" Height="220">
  <StackPanel Margin="20" Spacing="12">
    <Label Text="{Binding ClickMessage}" />
    <Label Text="{Binding ClickCount}" />
    <Button Text="Increment" Command="IncrementCommand" />
  </StackPanel>
</Window>
4. Main Entry Point (main.pb)PB
EnableExplicit

XIncludeFile "constants/AppConstants.pbi"
XIncludeFile "viewmodels/MainViewModel.pbo"

Protected *app.UI::Application = NewObject(UI::Application)
Protected *vm.MainViewModel    = NewObject(MainViewModel)
*vm\Init()

Protected *win.UI::Window = UI::XMLLoader::LoadView("views/MainView.xml", *vm)
If *win
  *win\Show()
  *app\Run()
  *win\Free()
EndIf

*vm\Free()
*app\Free()
