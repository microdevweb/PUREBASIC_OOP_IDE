GroupBox Class

UI Class

Visual grouping frame with title banner for organizing UI forms.

Description

The UI::GroupBox class (in framework/controls/GroupBox.pbi) encapsulates PureBasic's FrameGadget. It provides a visual framed border with a title caption to organize related controls.
