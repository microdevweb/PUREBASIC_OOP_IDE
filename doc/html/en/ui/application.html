Application Class

Core UI

Global application loop, dispatching, and lifecycle manager.

🖇 Inheritance Hierarchy
Core::Object → UI::Application

Description

The UI::Application class acts as the core application engine managing the master event loop (WaitWindowEvent) and automated OOP event dispatching.

Specific Methods

MethodDescription
Run()Runs the main event loop until all windows are closed.
Exit()Terminates application execution cleanly.
