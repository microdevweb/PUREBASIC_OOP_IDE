Component Class

Base UI

Abstract root class for all UI elements, gadgets, and responsive layout panels.

🖇 Inheritance Hierarchy
Core::Object → UI::Component
Derived Classes (inheriting from this class) :
UI::Gadget UI::Layouts::Container

Description

The abstract UI::Component class (located in framework/Component.pbo) provides the foundational WPF-style box model for all graphical elements in PureBasic OOP: computed bounds, responsive margins, horizontal/vertical alignments, desired dimensions, and automated 2-pass layout arrangement (Arrange).

Alignment Constants

ConstantValueMeaning
#UI_Align_Left0Align to left edge
#UI_Align_Center1Center horizontally
#UI_Align_Right2Align to right edge
#UI_Align_Stretch3Stretch across entire available width (default)
#UI_Align_Top0Align to top edge
#UI_Align_Middle1Center vertically
#UI_Align_Bottom2Align to bottom edge
#UI_Align_VStretch3Stretch across entire available height (default)

Core Component Methods

MethodDescription
SetPosition(x.i, y.i)Manually sets the X, Y position of the component.
SetSize(w.i, h.i)Manually sets width and height.
SetMargin(l.i, t.i, r.i, b.i)Sets external margins (Left, Top, Right, Bottom) in pixels.
SetMarginAll(m.i)Sets identical margin on all 4 sides.
SetHorizontalAlignment(align.i)Sets horizontal alignment (#UI_Align_Left, #UI_Align_Center, etc.).
SetVerticalAlignment(align.i)Sets vertical alignment (#UI_Align_Top, #UI_Align_Middle, etc.).
SetDesiredSize(w.i, h.i)Sets preferred size requested by component to layout panels.
GetDesiredWidth() / GetDesiredHeight()Returns desired dimensions including margins.
SetVisible(v.b) / IsVisible()Toggles element visibility.
SetEnabled(e.b) / IsEnabled()Toggles user interactivity.
Arrange(targetX.i, targetY.i, targetW.i, targetH.i)Calculates final bounding box and positions/resizes gadget.
