Official documentation for the PureBasic Object-Oriented framework.

Welcome to PureBasic OOP

PureBasic OOP brings full Object-Oriented Programming to PureBasic through a high-performance transpiler, a modern native UI library (WPF-style responsive layouts, 18 encapsulated gadgets), and a declarative MVVM architecture with two-way DataBinding.

💡 Contextual Help Key F1

In the IDE, place your cursor on any OOP keyword (Class, Method, Super, Property...), UI control (Window, Button, Editor, ListView, TreeView, StackPanel...), or MVVM class (ObservableObject, ViewModelBase, StringProperty...) and press F1 to open its detailed reference page with full inheritance hierarchy!
