Bienvenue dans PureBasic OOP

PureBasic OOP apporte la puissance de la Programmation Orientée Objet complète à PureBasic grâce à un transpileur optimisé, une bibliothèque UI native moderne (layouts WPF, 18 gadgets encapsulés) et une architecture MVVM déclarative avec DataBinding bidirectionnel.

💡 Touche d'aide contextuelle F1

Dans l'IDE, placez votre curseur sur n'importe quel mot-clé POO (Class, Method, Super, Property...), composant UI (Window, Button, Editor, ListView, TreeView, StackPanel...) ou classe MVVM (ObservableObject, ViewModelBase, StringProperty...) et appuyez sur F1 pour ouvrir directement sa fiche d'aide détaillée avec son arbre d'héritage !
