Classe Slider

UI Class

Curseur de réglage numérique interactif (TrackBar).

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Gadget → UI::Slider
Méthodes héritées de UI::Gadget (5 méthodes)
GetID() GetHandle() FreeGadget() SetToolTip() SetFocus()
Méthodes héritées de UI::Component (8 méthodes)
SetPosition() SetSize() SetMargin() SetHorizontalAlignment() SetVerticalAlignment() SetVisible() SetEnabled() Arrange()

Description

La classe UI::Slider encapsule le TrackBarGadget de PureBasic. Elle permet de sélectionner une valeur numérique continue entre deux bornes en déplaçant un curseur.

Constructeurs & Méthodes

SignatureDescription
Init(min.i = 0, max.i = 100, val.i = 0)Initialise le curseur avec ses bornes et sa valeur initiale.
GetValue() / SetValue(val.i)Lit ou met à jour la position courante du curseur.
GetMinimum() / GetMaximum()Retourne les valeurs minimale et maximale.
OnChange()Méthode virtuelle appelée lors du déplacement du curseur.
