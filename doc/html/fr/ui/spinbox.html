Classe SpinBox

UI Class

Boîte de saisie numérique avec boutons d'incrémentation/décrémentation.

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Gadget → UI::SpinBox
Méthodes héritées de UI::Gadget (7 méthodes)
GetID() GetHandle() SetFont() SetColor() FreeGadget() SetToolTip() SetFocus()
Méthodes héritées de UI::Component (8 méthodes)
SetPosition() SetSize() SetMargin() SetHorizontalAlignment() SetVerticalAlignment() SetVisible() SetEnabled() Arrange()

Description

La classe UI::SpinBox (dans framework/controls/SpinBox.pbi) encapsule le contrôle SpinGadget de PureBasic. Elle combine un champ de saisie textuel et deux boutons fléchés pour ajuster une valeur numérique avec précision.

Constructeurs

ConstructeurDescription
Init(min.i = 0, max.i = 100)Initialise la SpinBox avec les bornes minimale et maximale.
Init(x.i, y.i, w.i, h.i, min.i = 0, max.i = 100)Initialise avec coordonnées, dimensions et bornes absolues.

Méthodes Spécifiques

MéthodeDescription
GetValue()Retourne la valeur entière courante de la SpinBox.
SetValue(val.i)Définit la valeur de la SpinBox et met à jour son affichage.
GetMinimum() / SetMinimum(min.i)Lit ou modifie la borne minimale.
GetMaximum() / SetMaximum(max.i)Lit ou modifie la borne maximale.
OnChange()Méthode virtuelle appelée lors du changement de valeur.
