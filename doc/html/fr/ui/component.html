Classe Component

Base UI

Classe abstraite racine de tous les composants graphiques et conteneurs de layout réactifs.

🖇 Hiérarchie d'héritage
Core::Object → UI::Component
Classes dérivées (héritant de cette classe) :
UI::Gadget UI::Layouts::Container

Description

La classe abstraite UI::Component (dans framework/Component.pbo) définit le socle commun de l'ensemble des éléments d'interface graphique de PureBasic OOP. Elle fournit le modèle de boîte réactif inspiré de WPF : coordonnées calculées, marges (Margin), alignements horizontaux et verticaux, dimensions désirées, et cycle de disposition en 2 passes (Arrange).

Constantes d'Alignement

ConstanteValeurSignification
#UI_Align_Left0Alignement à gauche
#UI_Align_Center1Centrage horizontal
#UI_Align_Right2Alignement à droite
#UI_Align_Stretch3Étirer sur toute la largeur disponible (défaut)
#UI_Align_Top0Alignement en haut
#UI_Align_Middle1Centrage vertical
#UI_Align_Bottom2Alignement en bas
#UI_Align_VStretch3Étirer sur toute la hauteur disponible (défaut)

Méthodes Principales de Component

MéthodeDescription
SetPosition(x.i, y.i)Définit manuellement la position X, Y du composant.
SetSize(w.i, h.i)Définit manuellement la largeur et hauteur du composant.
SetMargin(l.i, t.i, r.i, b.i)Définit les marges externes (Gauche, Haut, Droite, Bas) en pixels.
SetMarginAll(m.i)Définit une marge externe identique sur les 4 côtés.
SetHorizontalAlignment(align.i)Définit l'alignement horizontal (#UI_Align_Left, #UI_Align_Center, etc.).
SetVerticalAlignment(align.i)Définit l'alignement vertical (#UI_Align_Top, #UI_Align_Middle, etc.).
SetDesiredSize(w.i, h.i)Définit la taille souhaitée demandée par le composant aux conteneurs de layout.
GetDesiredWidth() / GetDesiredHeight()Retourne les dimensions souhaitées avec marges.
SetVisible(v.b) / IsVisible()Active ou désactive la visibilité du composant.
SetEnabled(e.b) / IsEnabled()Active ou désactive l'interactivité utilisateur.
Arrange(targetX.i, targetY.i, targetW.i, targetH.i)Exécute le calcul de placement et redimensionne l'élément selon son alignement.
