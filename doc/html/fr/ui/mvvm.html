Architecture MVVM & DataBinding

MVVM Core

Pattern Model-View-ViewModel complet avec propriétés observables et liaison bidirectionnelle.

🖇 Hiérarchie d'héritage
Core::Object → MVVM::ObservableObject → MVVM::ViewModelBase

Présentation de l'Architecture MVVM

PureBasic OOP intègre un sous-système MVVM (Model-View-ViewModel) complet inspiré de WPF et .NET MAUI. Il permet de séparer totalement la logique métier (ViewModel) de l'interface utilisateur (View) grâce à un moteur de DataBinding réactif.

  • Model : Données et logique métier pure de l'application.
  • ViewModel : État réactif exposé sous forme de propriétés typées (StringProperty, IntProperty...) héritant de ViewModelBase.
  • View : Définition déclarative de l'interface (en XML ou en code POO) avec liaisons {Binding NomPropriete, Mode=TwoWay}.
  • BindingEngine : Synchronisation automatique bidirectionnelle entre les contrôles graphiques et le ViewModel.

Organisation des Dossiers & Stratégie des Includes

Une arborescence de projet standardisée et claire pour vos applications MVVM :

Structure recommandéeArborescence
MonProjetMVVM/
├── src/
│   └── ui/
├── constants/
│   └── AppConstants.pbi         ; Identifiants partagés (#PROP_..., #CMD_...)
├── models/
│   └── TaskModel.pbi            ; Données et structures pures (optionnel)
├── viewmodels/
│   └── TaskViewModel.pbo        ; Classe ViewModel héritant de MVVM::ViewModelBase
├── views/
│   └── MainView.xml             ; Définition déclarative XML de la vue
└── main.pb                      ; Point d'entrée principal de l'exécutable

Zéro-Include Framework : Grâce au transpilateur PBO intelligent, l'inclusion du framework (framework/UI.pbi) est automatique dès qu'un élément UI:: ou MVVM:: est détecté. Vous n'avez plus besoin d'inclure manuellement le framework !

Ordre d'inclusion dans votre main.pb :

EnableExplicit
; 1. Constantes partagées
XIncludeFile "constants/AppConstants.pbi"
; 2. Modèles de données (si existants)
; XIncludeFile "models/TaskModel.pbi"
; 3. ViewModels transpilés
XIncludeFile "viewmodels/TaskViewModel.pbo"

Classes de Propriétés Typées

ClasseType PureBasicMéthodes Clés
MVVM::StringProperty.s (Chaîne)GetValue(), SetValue(val.s), GetStringValue()
MVVM::IntProperty.i (Entier)GetValue(), SetValue(val.i), GetStringValue() (avec conversion automatique en texte)
MVVM::BoolProperty.b (Booléen)GetValue(), SetValue(val.b), GetStringValue()
MVVM::DoubleProperty.d (Flottant)GetValue(), SetValue(val.d), GetStringValue()

Exemple Complet en 4 Fichiers

1. Constantes Partagées (constants/AppConstants.pbi)PBI
#PROP_CLICK_MESSAGE = "ClickMessage"
#PROP_CLICK_COUNT   = "ClickCount"
#CMD_INCREMENT      = "IncrementCommand"
2. Le ViewModel (viewmodels/MainViewModel.pbo)PBO
XIncludeFile "../constants/AppConstants.pbi"

Class MainViewModel Extends MVVM::ViewModelBase {
  Public *ClickMessage.MVVM::StringProperty
  Public *ClickCount.MVVM::IntProperty
  
  Public Method Init() {
    Super\Init()
    This\*ClickMessage = This\BindString(#PROP_CLICK_MESSAGE, "Bienvenue !")
    This\*ClickCount   = This\BindInt(#PROP_CLICK_COUNT, 0)
  }
  
  Public Method OnCommand(cmdName.s) {
    If cmdName = #CMD_INCREMENT
      Protected count.i = This\*ClickCount\GetValue() + 1
      This\*ClickCount\SetValue(count)
      This\*ClickMessage\SetValue("Clic n° " + Str(count) + " enregistré !")
    EndIf
  }
}
3. La Vue Déclarative (views/MainView.xml)XML
<Window Title="Démo MVVM" Width="420" Height="220">
  <StackPanel Margin="20" Spacing="12">
    <Label Text="{Binding ClickMessage}" />
    <Label Text="{Binding ClickCount}" />
    <Button Text="Incrémenter" Command="IncrementCommand" />
  </StackPanel>
</Window>
4. Le Point d'Entrée (main.pb)PB
EnableExplicit

XIncludeFile "constants/AppConstants.pbi"
XIncludeFile "viewmodels/MainViewModel.pbo"

Protected *app.UI::Application = NewObject(UI::Application)
Protected *vm.MainViewModel    = NewObject(MainViewModel)
*vm\Init()

Protected *win.UI::Window = UI::XMLLoader::LoadView("views/MainView.xml", *vm)
If *win
  *win\Show()
  *app\Run()
  *win\Free()
EndIf

*vm\Free()
*app\Free()
