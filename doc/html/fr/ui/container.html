Classe Container

WPF Layout

Classe abstraite racine des conteneurs de disposition réactifs (WPF-style).

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Layouts::Container
Classes dérivées (héritant de cette classe) :
UI::Layouts::StackPanel UI::Layouts::DockPanel UI::Layouts::Grid
Méthodes héritées de UI::Component (11 méthodes)
SetPosition(x, y) SetSize(w, h) SetMargin(l, t, r, b) SetMarginAll(m) SetHorizontalAlignment(align) SetVerticalAlignment(align) SetVisible(v) SetEnabled(e) Arrange(rx, ry, rw, rh) GetDesiredWidth() GetDesiredHeight()

Description

La classe abstraite UI::Layouts::Container (héritant de UI::Component) est la base de tous les panneaux de disposition automatique réactive. Elle gère la liste dynamique des composants enfants (Children), les marges intérieures (Padding) et le calcul en cascade de la disposition.

Méthodes Principales de Container

MéthodeDescription
AddChild(*child.UI::Component)Ajoute un composant enfant au conteneur.
RemoveChild(*child.UI::Component)Retire un composant du conteneur.
ClearChildren()Supprime tous les composants enfants.
GetChildCount()Retourne le nombre d'enfants gérés.
GetChild(index.i)Retourne le pointeur vers l'enfant à l'index donné.
SetPadding(l.i, t.i, r.i, b.i)Définit les marges intérieures du conteneur en pixels.
SetPaddingAll(p.i)Définit une marge intérieure identique sur les 4 côtés.
