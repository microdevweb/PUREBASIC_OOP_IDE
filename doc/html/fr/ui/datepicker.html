Classe DatePicker

UI Class

Sélecteur de date et calendrier natif avec formatage personnalisable.

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Gadget → UI::DatePicker
Méthodes héritées de UI::Gadget (7 méthodes)
GetID() GetHandle() SetFont() SetColor() FreeGadget() SetToolTip() SetFocus()
Méthodes héritées de UI::Component (8 méthodes)
SetPosition() SetSize() SetMargin() SetHorizontalAlignment() SetVerticalAlignment() SetVisible() SetEnabled() Arrange()

Description

La classe UI::DatePicker (dans framework/controls/DatePicker.pbi) encapsule le contrôle DateGadget de PureBasic. Elle permet à l'utilisateur de choisir une date via un calendrier déroulant interactif avec masque de format personnalisable.

Constructeurs

ConstructeurDescription
Init(mask.s = "%dd/%mm/%yyyy")Initialise le DatePicker avec le format de date spécifié (par défaut jour/mois/année).
Init(x.i, y.i, w.i, h.i, mask.s = "%dd/%mm/%yyyy")Initialise avec position et dimensions absolues.

Méthodes Spécifiques

MéthodeDescription
GetDate()Retourne la date sélectionnée sous forme de timestamp PureBasic (entier).
SetDate(date.i)Définit la date sélectionnée via un timestamp PureBasic.
GetDateString(mask.s = "")Formate et retourne la date sous forme de chaîne de caractères selon le masque.
SetMask(mask.s)Modifie le masque de format d'affichage de la date.
OnChange()Méthode virtuelle appelée lors de la modification de la date sélectionnée.
